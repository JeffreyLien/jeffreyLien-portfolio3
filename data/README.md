# Generated synthetic data

The row-level source and processed CSV files are intentionally not committed to the public portfolio. They contain only synthetic student records and can be regenerated by running the notebooks in order:

1. `01_generate_synthetic_data.ipynb`
2. `02_data_quality_and_cleaning.ipynb`

The cleaned data then feed the SQLite warehouse, analytical notebooks, and reporting exports.

No real student or institutional records are used.
