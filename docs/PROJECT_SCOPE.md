# Project Scope

This project brings together a set of institutional-research workflows using fully synthetic student data.

## Analytical areas

- Student enrollment, persistence, and cohort retention
- Course withdrawal, failure, and credit-completion patterns
- Advising contacts and student-support operations
- Quantitative and qualitative student-feedback analysis
- Program-level KPI reporting
- External-submission validation and reconciliation

## Data workflow

The notebooks move from synthetic source generation through data-quality checks, cleaning, relational warehouse construction, analysis, and reporting exports. Standalone SQL files mirror common recurring institutional-research queries, while the Excel and Power BI materials show how the same metrics can be communicated in operational reporting.

## Interpretation

All records and outcomes are synthetic. Relationships are described as observed or associated unless the design supports a stronger interpretation. Student-level reporting in a production setting would require appropriate access controls and institutional privacy procedures.
